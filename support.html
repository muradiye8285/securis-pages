Troubleshooting

  1. Make sure your device is running iOS or iPadOS 17 or later.
  2. Close and reopen Securis if a screen appears stale.
  3. Run a new security check from the Home screen.
  4. If Securis Pro is not active, open Settings in the app and tap Restore Purchase.
  5. If scan history looks outdated, use Clear Scan History in Settings and run a new check.

About Securis Checks

Securis provides privacy and security recommendations based on available system signals and user-guided checks. It is not an antivirus and does not scan the entire device.

When contacting support, include:

  • A screenshot if it helps explain the problem
